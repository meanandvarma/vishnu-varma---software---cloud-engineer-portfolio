# Project Screen Recordings

Place `.mp4` or `.webm` screen recordings of Vishnu's applications in this folder, for example:
- `prepai-demo.mp4`
- `talktime-demo.mp4`
- `quizint-demo.mp4`
- `devops-demo.mp4`

Then open `src/data/projects.ts` and set `video: '/videos/prepai-demo.mp4'` and `videoDuration: '1:45'` on the corresponding project entry.
